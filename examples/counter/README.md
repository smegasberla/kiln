# Counter

A real app scaffolded by `voussoir init` and kept in-tree so the template is
continuously buildable.

```sh
voussoir build --size     # from this directory
voussoir dev
```

`native/src/assets.rs` is generated by `voussoir build` and is git-ignored, so a
plain `cargo build` in `native/` needs one `voussoir build` (or `voussoir dev`) first.

State lives in Rust: `shift` returns the new counter over IPC and also emits it
on the `count` event, so the page renders whatever the shell tells it.
