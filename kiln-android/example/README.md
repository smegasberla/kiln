# Android example

A real Kiln app on Android, kept in-tree so the templates stay buildable.

```sh
kiln android build            # APK for arm64-v8a
kiln android build --abi x86_64   # emulators on x86 hosts
kiln android run              # install and follow logs
```

The Gradle files here are generated by `kiln init` and are yours to edit. The
Kotlin under `app/src/main/java/` is **not** here: wry writes it during the build,
which is why the project ignores it.
